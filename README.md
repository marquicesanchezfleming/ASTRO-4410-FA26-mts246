# ASTRO 4410 Multiwavelength Astronomical Techniques - FA26 - mts246
This repository houses all code written and developed for the ASTRO 4410 course at Cornell University, taken in Fall 2026
under Prof. Gordon Stacey and Prof. James Cordes. Specifically, this repository houses modules--folders--for each of the 
five labs we worked on in the class. They are, in order:

## Lab 1: CCD characterization
## Lab 2: Imaging and Photometry
## Lab 3: Spectroscopy
## Lab 4: TBD
## Lab 5: Radio Spectra

All code is publically available, though both the simlulated data and the real data collected in the lab, have not been pushed
to Github, that is, they are not found in this repository. That said, the code used to create such simulated data is in the 
repository, so analysis can still be carried out.
